# GitFlow

## 📜 Aspectos generales

Durante todo el desarrollo de todo nuestro TP decidimos que vamos a estar utilizando un modelo de GitFlow que consta de 4 ramas principales enumeradas a continuacion y ordenadas en base a funcionalidad entregable:

  - **Main:** La rama main sera la que se presentara en las correspondientes entregas. La misma presentara codigo que ya fue testeado y aprobado. Todo cambio en las ramas anteriores deberan subirse mediante un Pull Request.
  - **Release:** Esta rama es la encargada de portar el codigo ya testeado en la fase anterior pero que todavia no posee el visto bueno para ser de caracter entregable. 
  - **Develop:** Toda funcionalidad desarrollada con anterioridad pero que se encuentra en proceso de testing debera albergarse en esta rama. Todo lo trabajado en las ramas de Features sera mergeado a esta rama.
  - **Features:** En estas multiples ramas se desarrollaran las funcionalidades requeridas del TP.
